# GPU Memory Management

This branch does not run a GPU-resident vector database. GPU memory is used by
the Cosmos Embed (CE1) service only.

See the CE1 / Compose deployment guides for `COSMOS_EMBED_GPUS` and related
settings. For vector search resource planning on VAST, see the
[VastDB architecture](../docs/vastdb-architecture.md) page and VAST Query Engine
documentation.
