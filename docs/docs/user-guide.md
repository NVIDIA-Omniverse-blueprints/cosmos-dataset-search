# CDS User Guide

After successfully deploying CDS, use the CLI or REST API depending on your workflow.

## Interaction Methods

CDS provides two ways to interact with the system:

1. **Command Line Interface (CLI)** - Built on top of the REST API, offering a simplified interface for common tasks including collection management, ingestion, and search
2. **REST API** - Direct programmatic access via HTTP/curl for custom integrations

## Getting Started

These user guides are the recommended next steps after a successful deployment.

Choose the interface that best fits your workflow:

### Command Line Interface

Simplified command-line tools for collection management, ingestion, and search operations.

**[CLI User Guide](cli-user-guide.md)**
